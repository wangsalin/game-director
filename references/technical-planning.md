# 技术选型与工程准备

已有工程先核实实际引擎、版本、依赖和运行方式；没有明确理由不要换栈。需要新增能力时核对当前版本官方文档与目标平台限制，不能编造 SDK 接口、发布条件或插件支持。

小型 Web 原型可按[原型执行](prototyping.md)使用无运行时第三方依赖的底座；自动浏览器验收的 Playwright 是独立开发工具。已有引擎/框架/平台选择优先，原生与目标设备验证不由浏览器检查代替。

引擎工程按[专项路由](engines/README.md)选择 Godot、Unity、Unreal 或 Cocos Creator，读取对应版本/导入/场景与脚本/资源/调试/构建和产物验收流程；可用只读工具检查元数据，不能把识别成功当构建通过。Creator 3.x、旧 2.x 与 Cocos2d-x 分开处理。

## 候选比较

| 候选 | 适合优先评估的情况 | 必须核实的限制 |
|---|---|---|
| 原生 Web / 轻量 Web 游戏库 | 小型 2D、链接即玩、简单交互 | 渲染/输入/音频/资源能力、目标浏览器、存档可靠性 |
| Cocos Creator | 2D/轻量 3D、移动及小游戏目标 | 精确引擎版本、目标渠道导出、包体、真机与 SDK |
| Godot | 2D 或适中 3D、团队熟悉其工具链 | 目标平台导出与插件、Web/移动限制、发布工具 |
| Unity | 工具生态、复杂交互、多平台 2D/3D | 精确版本、目标设备、构建模块、适用授权与平台适配 |
| Unreal Engine | 高质量 3D、复杂场景或已有 UE 团队 | 目标硬件、性能/包体、制作成本、适用授权与部署 |

这张表是比较方向，不是兼容保证。微信小游戏不等于普通 H5，也不等于工具类小程序；使用当前环境可用的平台专项 Skill，核实引擎和渠道的实际能力。没有官方核实或实际导出证据时标为未验证。

## 架构最小范围

记录核心规则模块、状态/场景、输入、渲染/资源、存档与平台适配边界。核心逻辑通过适配器访问平台，不在规则里直接调广告、支付或社交 API。数值使用现有配置机制，不为小项目新增服务器、队列或复杂框架。

联网项目明确权威端、身份/权限、匹配/房间、同步/重连、重复请求、超时/失败和成本边界。离线单机不增加无关联网系统。广告/付费接口先定义失败与重复回调行为，只有真实接入并测试才标为已接通。

## 数据、性能与运行

使用[TDD](../templates/TDD_TEMPLATE.md)与[数据模板](../templates/DATA_SCHEMA_TEMPLATE.md)记录字段约束、版本、存档损坏处理、迁移兼容和备份方式。核实写入目标环境，不能拿生产数据做试验。

性能预算与目标设备相关：帧时间/FPS、内存、场景加载、包体、并发实体、纹理/音频、3D draw call/面数等只列适用项，给预算来源与测量方法。数值是预算或测量，不能混写。说明开发/构建/测试命令、必需工具和未配置项，不把未执行命令当成已通过。
