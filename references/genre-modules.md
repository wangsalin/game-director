# 游戏类型专项文档路由

| 类型 | 专项设计内容 |
|---|---|
| 俄罗斯方块/消除 | 棋盘状态、生成规则、匹配判定、连锁、计分、难度曲线 |
| Roguelite | 随机池、局内构筑、局外成长、掉落、稀有度、流派平衡 |
| 动作/射击 | 输入、移动、瞄准、弹道、碰撞、伤害、敌人 AI、Boss |
| 模拟经营 | 资源经济、生产链、订单、定价、NPC、事件、离线收益 |
| 宠物养成 | 状态属性、需求衰减、互动、成长阶段、情绪、日程、离线时间 |
| 解谜 | 谜题规则、状态空间、答案校验、提示、难度分级、关卡编辑 |
| 平台跳跃 | 物理参数、跳跃曲线、碰撞、移动平台、摄像机、关卡节奏 |
| RPG | 属性、职业、技能树、装备、任务、剧情分支、战斗结算 |
| 卡牌构筑 | 卡牌数据库、费用、效果栈、目标规则、抽牌、牌组限制 |
| 塔防 | 路径、敌人波次、塔属性、目标选择、射程、升级和经济 |
| 文字冒险 | 章节树、对话节点、分支条件、变量、结局、存档节点 |
| 赛车 | 车辆参数、操控模型、赛道、碰撞、AI 对手、计时和回放 |
| 生存建造 | 资源采集、制作配方、建造网格、昼夜、危险、世界生成 |
| 多人竞技 | 权威服务器、同步模型、延迟补偿、匹配、断线重连、反作弊 |
| 3D 探索冒险 | 摄像机、导航、交互、关卡空间、动画状态机、性能预算 |

## 参考游戏改编
1. 研究官方商店、开发者资料、公开演示和可靠玩家反馈。
2. 标记事实、推断和未知；未试玩不能声称实测。
3. 拆解核心循环、操作、进度、数值、内容结构和商业化。
4. 分析目标平台的操作、性能和内容适配。
5. 设计原创名称、世界观、美术、UI 和具体内容。
6. 不复制源代码、商标、角色、美术、音乐、文本或专有资产。
