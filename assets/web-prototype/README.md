# Web 可玩原型

这是“信标小径”回合制网格收集游戏的真实可玩底座。若用户要求其他机制，需要改写规则、表现与测试，不能只改名字交付。当前使用临时几何图形，无远程资源、联网、付费接口或生产素材。

## 运行

在本目录运行（Python 3，命令只服务当前项目）：

```text
python -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8000`。停止时按 Ctrl+C。采用 ES 模块，应通过本地 HTTP 运行，不能承诺双击 HTML 可用。端口占用时换端口。运行不需要 npm 安装。

方向键/WASD 或屏幕方向按钮移动；P 暂停，R 重开。收集两片后到灯塔获胜；每步耗一格能量，遇风暴或能量耗尽失败。碰墙/边界不扣能量。通关次数保存在当前浏览器本地，刷新回标题，不恢复未完成棋局。无账号或云存档。

## 调参与规则

- [config.js](config.js)：名称、地图、初始能量、障碍与目标。初值待试玩调参。
- [规则](src/rules.js)：独立状态转换，无浏览器依赖；结算顺序写在源文件。
- [输入与渲染](src/main.js)、[页面](index.html)、[样式](style.css)。
- [规则测试](tests/rules.test.js)：Node 20+，运行 `node --test tests/rules.test.js`，也可 `npm test`。不需要先安装依赖。
- [浏览器计划](browser-plan.json)：从初始状态用真实输入验证赢、输、重开、暂停、存档及方向按钮。改变规则时同步路线与准确预期，不能删失败断言冒充通过。

## 浏览器验收

已随创建脚本复制自包含的 `tools/web-check/` 工具；源模板目录尚未复制该工具。生成项目后在工具目录 `npm ci`，使用其 README 的命令。它依赖 Playwright 及可用的 Chromium/Chrome/Edge。工具或浏览器缺失时为 not_run，不能把“未运行”解释为“通过”。

手工验收不依赖 Skill：开始→收集→通关→重开；另测下、右进入风暴后重开、暂停时方向无效、刷新后保留通关数，观察浏览器控制台。自动工具不能替代视觉检查、玩家试玩或实体手机验证。

## 当前状态与继续开发

创建脚本不会替你运行检查。尚无本项目证据时，规则、浏览器、移动端及体验均记未验证。运行后保留 JSON、截图、命令、环境和实际失败记录；不要预填 passed。

继续开发先读当前规则/配置/报告与用户授权。保留已验证玩法，按需要拆关卡、替换临时素材或接入已有引擎；依赖、数据/存档、输入与规则改变后复测。当前是原型，不是生产就绪或发布就绪。工具的 MIT 许可在生成项目 `tools/web-check/LICENSE`，不替用户决定整个游戏的授权协议。
