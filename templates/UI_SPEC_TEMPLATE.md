# UI / UX Specification

> 写作说明：先写真实流程与输入，再给可实施视觉规格。无对应功能的页面不新增；原型标明设计参考或生产实现。

## 页面与导航

| 页面/弹层 ID | 目的/关键数据 | 入口/出口/返回 | 条件与权限 | 关联规则 |
|---|---|---|---|---|

描述开始一局、操作/暂停、成长选择、结算/重试、保存/返回的适用路径；弹层是否暂停、叠加优先级和输入穿透必须明确。

## 页面/HUD 规格

每页写层级、关键区域位置、信息优先级、按钮行为、快捷键/触控/手柄焦点、实际存在的空/加载/错误/禁用状态。HUD 标注常驻与展开信息、遮挡和反馈。

## 视觉与适配

目标分辨率、横竖屏、安全区、缩放/断点；字体/中文回退、字号、颜色语义、间距、触控命中区、图标和动画参数。给具体值或可验证约束及理由，不只写“简洁美观”。

## 原型与验收

记录原型/场景实际路径、design_reference 或 production_ui、运行方式、演示数据标识、已实现交互及未实现项。检查目标屏幕、输入、中文截断、焦点、暂停恢复、重复点击及错误输出，保存观察与未测范围。
