# Test Report

> 写作说明：只有实际运行才填写 passed/failed；未执行为 not_run，环境/依赖阻断为 blocked。报告保存证据，不复制测试计划当结果。

## 本轮环境

日期、构建/提交、引擎/运行时、平台/设备、输入、相关配置（脱敏）、测试范围和限制。

| 用例/检查 ID | 实际命令/操作与工作目录 | 预期 | 实际结果/退出码 | passed/failed/blocked/not_run | 日志/截图/观察位置 | 缺陷 |
|---|---|---|---|---|---|---|

## 关键流程观察

记录真实输入到结算的结果、异常路径和修复复测；编译通过不替代流程验证，模拟器通过不替代真机。

## 退出结论

对照本阶段既定标准说明满足项、未满足项、接受的非阻断缺陷及依据。列未执行的设备/平台/外部服务测试与原因，不将未验证项算入通过。
